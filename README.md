# استبيان تقييم الاستراتيجية 2027-2030

صفحة استبيان ثابتة (HTML واحد) لتنسيقية الأحزاب والتكتلات السياسية الليبية.

## النشر على Cloudflare Pages
- Framework preset: None
- Build command: (اتركه فارغاً)
- Build output directory: `site`

## كيف يعمل
- المشاركون يملؤون الاستبيان ويضغطون «حفظ الإجابات»، وتُرسل الإجابات إلى Google Apps Script
  وتُخزَّن في Google Sheet (تبويب «الإجابات»).
- زر Admin أعلى الصفحة يفتح دخول المشرفين، وبعده يظهر زر تصدير Excel أسفل الصفحة.
- رابط خدمة التجميع في المتغير `SYNC_URL` داخل `site/index.html`.

## ملاحظات
- كلمات مرور المشرفين وكود Apps Script غير موجودين في هذا المستودع عمداً.
